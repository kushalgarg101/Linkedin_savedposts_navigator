# Contributing to LinkedIn Saved Navigator

Thank you for your interest in contributing to LinkedIn Saved Navigator! We welcome contributions from the community to help make this tool better for everyone.

## Getting Started

1. **Fork the Repository**: Create a personal fork of the project on GitHub.
2. **Clone the Fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/linkedin-saved-navigator.git
   cd linkedin-saved-navigator
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```

## Development Workflow

1. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. **Make Your Changes**: Implement your feature or bug fix.
3. **Run Tests**:
   Ensure all tests pass before submitting your changes.
   ```bash
   npm test
   ```
   
4. **Commit Your Changes**:
   Use descriptive commit messages.
   ```bash
   git commit -m "feat: add support for XYZ"
   ```
5. **Push and Open a Pull Request**:
   Push your branch to your fork and open a PR against the `main` branch.

## Coding Standards

- Follow the existing code style (ES Modules).
- Ensure all new features are covered by tests.
- Keep the UI responsive and aligned with LinkedIn's aesthetics.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on the GitHub repository with a detailed description and steps to reproduce.

Happy coding!
